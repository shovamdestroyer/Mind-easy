College Mini Project

About MindEase AI

An academic web engineering project exploring affective computing, audio synthesis, and accessible digital wellness.

🎓

Project Overview

MindEase AI was engineered as an innovative college mini project addressing academic fatigue, digital burnout, and cognitive stress among students and professionals through client-side wellness technologies.

  • Category: Human-Computer Interaction & AI for Health
  • Core Tenet: Zero-friction accessibility (No mandatory backend or signups required)
  • Privacy First: All sessions and credentials persist strictly within client-side LocalStorage
⚙️

Technical Architecture

Built using modern, standards-compliant web technologies without bulky third-party frontend frameworks:

HTML5 Semantic DOM CSS3 Glassmorphism Vanilla JavaScript (ES6+) Web Speech API (TTS) Web Audio API Synthesis LocalStorage Persistence Google Gemini API (Optional)
🛡️

Ethics & Non-Medical Scope

MindEase AI is an educational stress-reduction and mindfulness tool. It is intentionally designed without diagnostic capabilities. In academic evaluation and everyday use, it demonstrates how browser APIs can deliver therapeutic ambient experiences responsibly.
